# jisk-dockey.github.io

Website for **Jisk Dockey**, club night design for underground nights in Glasgow and Edinburgh.

Live at https://jisk-dockey.github.io

- `index.html` is the whole site: one page with no build step. Edit it and push to `main`, and GitHub Pages republishes it within a minute or two.
- Enquiries go to jiskdockeypromotions@gmail.com. The contact form opens the visitor's email app with the details filled in, because a static site has no server to send from.
